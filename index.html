sayNset 隐私政策

最后更新日期：2026年7月4日

概述

sayNset 是一款本地语音助手应用，致力于保护您的隐私。本隐私政策说明我们如何收集、使用和保护您的数据。

我们收集的数据

1. 语音录音

  • 用途：将您的语音转换为文字并识别意图
  • 存储：录音文件临时存储在设备本地，识别完成后自动删除
  • 不上传：语音录音不会上传到任何服务器

2. 识别文本

  • 用途：将识别出的文字发送到云端 API 进行意图理解
  • 传输：仅传输文字内容，不包含语音录音
  • 存储：识别历史存储在设备本地

3. 系统数据

  • 用途：执行您的语音指令（如创建闹钟、日程、提醒等）
  • 权限：仅在您授权后访问日历、提醒事项、通讯录等系统数据

第三方服务

阿里云函数计算

  • 用途：作为 API 代理，转发意图识别请求
  • 数据：仅传输识别文本，不存储任何数据

DeepSeek API

  • 用途：理解语音指令的意图
  • 数据：仅传输识别文本和系统提示词
  • 存储：DeepSeek 不存储用户请求内容

数据安全

  • 所有语音识别在设备本地完成（whisper.cpp）
  • API 通信使用 HTTPS 加密
  • API 密钥存储在服务器端，不包含在客户端
  • 不收集任何个人身份信息
  • 不进行用户追踪

您的权利

  • 撤销权限：可在系统设置中随时撤销麦克风、日历等权限
  • 删除数据：可随时删除识别历史和临时录音文件
  • 取消订阅：可在 App Store 设置中取消订阅
