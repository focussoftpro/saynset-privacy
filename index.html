sayNset 隐私政策

最后更新日期：2026年11月17日

概述

sayNset 是一款语音助手应用。语音识别在您自己的 iPhone 上本地完成；需要云端意图理解时，只发送识别出的文字和必要的系统提示词。本政策同时适用于 iPhone 和 Apple Watch 端。

我们处理的数据

1. 语音录音

  • 用途：将您主动说出的语音指令转换为文字，以便理解和执行指令。
  • 本地识别：语音转文字由配对 iPhone 上的 whisper.cpp 完成。语音录音不会上传到阿里云、DeepSeek 或其他云服务器。
  • iPhone 录音：按住麦克风按钮时录音，松开后进入识别；识别流程结束（包括失败、取消或过期）后删除临时音频，不作为历史录音保存。
  • Apple Watch 录音：打开 Watch App、复杂功能或回前台不会自动录音；按住麦克风按钮时开始录音，松开后结束并发送，不因静音或固定时长自动结束。终态后不持续监听，再次按住才开始下一句。
  • 设备间传输：Watch 录音通过 Apple 的 WatchConnectivity 发送到您自己的配对 iPhone。Watch 不直接联系 DeepSeek，也不将音频发送到云端。
  • 待处理保留：手机锁定、未连接、未启动或无法及时处理时，Watch 会保留待处理录音，手机也会保留已收到但尚未处理的收件音频，以便恢复后继续。等待您在 iPhone 上确认时，录音保留到成功、失败、取消、过期等最终结果；不是每次传输或识别后立即删除。
  • 异常文件：损坏或校验失败的录音可能移至设备本地隔离区，不会被作为有效指令执行。删除相应设备上的 App 可清除其沙箱内保留的音频。

2. 识别文本与历史

  • 本地处理：部分明确的指令可直接在设备本地完成意图识别。
  • 云端处理：需要 AI 意图理解时，仅将识别出的文字和必要的系统提示词发送到云端 API，不发送语音录音。
  • 本地历史：识别文字、执行结果、时间和来源（iPhone 或 Apple Watch）保存在 iPhone 本地，历史记录不包含源录音。
  • 删除方式：可在 iPhone App 的“设置”中使用“清除识别历史”，确认后删除全部本地文字历史及旧版本可能遗留的录音文件。Watch 尚未处理的录音不适用该按钮，可按上述规则等待处理完成或删除 Watch App。

3. 系统数据

  • 用途：执行您的语音指令（如创建闹钟、日程、提醒等）。
  • 权限：仅在您授权后访问麦克风、日历、提醒事项、通讯录等系统数据。电话和短信会打开系统界面供您确认，不会在未确认时自动拨号或发送。

第三方服务

阿里云函数计算

  • 用途：作为 API 代理，转发需要云端处理的意图识别请求。
  • 数据：传输识别文本和必要的系统提示词，不传输语音录音。

DeepSeek API

  • 用途：理解需要云端处理的语音指令文本。
  • 数据：由代理服务传输识别文本和必要的系统提示词。
  • 第三方处理：相关服务的数据处理与保留以其隐私政策和服务条款为准。

数据安全

  • 所有语音转文字均在您的 iPhone 本地完成（whisper.cpp）。
  • API 通信使用 HTTPS 加密；设备间通信使用 Apple 的配对设备传输机制。
  • API 密钥存储在服务器端，不包含在客户端。
  • 不进行用户追踪，不使用广告或统计分析服务。
  • 您主动说出的内容可能包含个人信息，请避免在语音指令中口述不必要的敏感信息。

您的权利

  • 撤销权限：可在系统设置中随时撤销麦克风、日历等权限。
  • 删除数据：可在 iPhone App 设置中确认清除文字历史；临时音频按上述生命周期删除。删除相应设备上的 App 可清除其沙箱内保留的数据。
  • 取消订阅：可在 App Store 设置中取消订阅。
